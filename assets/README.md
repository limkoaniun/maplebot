# Character templates

`player-nametag.png` and `player-head.png` are small crops prepared from the user's local game capture for this character's tracker. They are also required by the recorded nametag regressions in `tests/test_recorded_nametags.py`.

The Construction Site example uses these paths. A different character or appearance needs new calibration; do not replace these regression assets silently. Full captures are kept locally under ignored directories.
