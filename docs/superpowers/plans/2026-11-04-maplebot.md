# maplebot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A test-driven, pure-vision MapleStory auto-leveling bot (route following, monster detection, combat, potions, stuck recovery) runnable on Windows and fully unit-tested headless in WSL.

**Architecture:** Pure functions in `maplebot/vision`, `maplebot/nav`, `maplebot/brain` take numpy frames and return dataclasses; `maplebot/bot.py` wires them into a 12 fps loop; capture and keyboard run in their own threads behind small interfaces with fake implementations for tests.

**Tech Stack:** Python 3.11+, OpenCV, numpy, PyYAML, mss, pynput, pywin32, pytest.

**Spec:** `docs/superpowers/specs/2026-11-04-maplebot-design.md`

## Global Constraints

- Python ≥ 3.11; tests run under `.venv/bin/pytest` in WSL with `opencv-python-headless`.
- Nothing under `tests/` or in `maplebot/vision`, `maplebot/nav`, `maplebot/brain`, `maplebot/health.py` imports `mss`, `pynput`, `win32gui`, `pyautogui`.
- Asset formats are the reference formats: route colour codes are RGB keys like `"255,0,0": "left none none"`; route/map PNGs are read with `IMREAD_COLOR` (BGR); monster templates key out pure green `(0,255,0)` or alpha < 128.
- `Command` fields: `move_x ∈ {none,left,right,stop}`, `move_y ∈ {none,up,down,stop}`, `action ∈ {none,jump,attack,aoe,teleport,goal}`.
- No per-pixel Python loops in vision/nav hot paths.
- Commit after every task; conventional commit messages.

## Review Focus

1. Frame smaller than a template (player at map edge, tiny window): `match_template` must pad instead of raising — Task 2 `test_match_pads_small_image`.
2. Minimap not found for a frame (map transition, loading screen): bot keeps last minimap and skips navigation, never crashes — Task 3 `test_find_minimap_returns_none_without_border`, Task 13 `test_step_without_minimap_does_not_raise`.
3. Route PNG where the player stands on no route colour (fell off): keep last move for `miss_grace_frames` then stop — Task 7 `test_nearest_command_none_outside_radius`, Task 10 `test_hunting_stops_after_grace`.
4. Both-sides monsters at equal distance: no attack rather than flip-flopping — Task 9 `test_choose_target_tie_returns_none`.
5. Potion key held/spammed when the bar is misread as 0% on the first frames: warm-up reads ignored and re-arm required — Task 6 `test_policy_ignores_warmup_reads`, `test_policy_requires_rearm`.
